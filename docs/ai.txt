AI Usage Disclosure

This project made use of AI tools during development, in the following ways:

1. Documentation: AI was used to help draft documentation such as README.md, Javadoc comments, and pull request summaries. All AI-generated content was manually reviewed by team members for accuracy before being committed.

2. Code Review: Some team members used AI to review code changes as a way to catch issues faster and improve development efficiency.

3. GUI Bug Fixes: While building the GUI, AI was used to help fix a number of tricky bugs.

4. Testing: Some test code was written with AI assistance during the testing phase.

5. Presentation Visuals: The comics/illustrations and diagrams used in the presentation slides were generated by AI (Gemini).
